# Event Loop

## Микрозадачи и макрозадачи

Цикл событий сначала выполняет стек, затем микрозадачи, затем одну макрозадачу.

> [!warning] Частая ошибка
> Не путайте `setTimeout` с гарантированным временем запуска.

> [!question]- Почему setTimeout(fn, 0) выполняется после Promise.then?
> `then` ставит колбэк в очередь микрозадач.
>
> ```js
> Promise.resolve().then(() => log('B'))
> setTimeout(() => log('A'), 0)
> ```

## Очереди

> [!question]+ Какие задачи относятся к микрозадачам?
> - `Promise.then`
> - `queueMicrotask`
> - `MutationObserver`

> [!question] Что такое макрозадача?
> Задача из очереди таймеров, ввода-вывода или UI-событий.
