# Архитектура web. Evolution Design, small

Порядок FSD без его сетки из 6 слоев. Фичи крупные, у каждой своя страница или свой кусок экрана. Вариант small разрешает импорт фичи из фичи.

## Дерево

```
src/
  main.tsx            точка входа
  index.css           Tailwind и тема
  app/                запуск, роутер, провайдеры, страницы из нескольких фич
    pages/            OnboardingPage, SettingsPage
  features/
    auth/             вход через GitHub, useMe
    sources/          загрузка конспектов из GitHub и локальной папки, кэш, useCards
    ai/               ключ ИИ, шторка «Спросить», советы, ИИ-карточки, ссылка ChatGPT
    session/          карточка, свайп, шторка конспекта, итоги сессии
    dashboard/        главный экран, график активности, статистика
  shared/
    ui/               компоненты shadcn/ui, GradientBackground, Markdown
    lib/              утилиты, cn
    api/              http-клиент, очередь ответов
```

Внутри фичи группы `ui/`, `model/`, `api/` и `index.ts`. Алиас `@/` указывает на `src/`.

## Импорты

| откуда | можно импортировать | правило |
|--------|---------------------|---------|
| `app` | все | |
| `features` | `shared`, другие фичи через их `index.ts` | `ed-no-app` |
| `shared` | только `shared` | `ed-shared-no-services` |

`@notes-cards/core` можно импортировать отовсюду, это общий пакет монорепо без React.

## Public API

1. У каждой фичи `index.ts`, правило `ed-public-api`. Снаружи импортируют только его, например `@/features/auth`.
2. `ui`, `model`, `api` внутри фичи снаружи не импортируют.
3. У `shared` нет общего индекса, импорт по сегментам, например `@/shared/ui/Markdown`.

## Куда класть

| новый код | путь |
|-----------|------|
| вход, профиль, выход | `features/auth/` |
| загрузчик конспектов, разбор, кэш IndexedDB | `features/sources/` |
| запросы к ИИ, форма ключа, шторка ответа | `features/ai/` |
| экран сессии, свайп, итоги | `features/session/` |
| главный экран и его виджеты | `features/dashboard/` |
| страница из нескольких фич (мастер, настройки) | `app/pages/` |
| роутер, провайдеры, глобальные стили | `app/` |
| компонент shadcn/ui, Markdown, фон | `shared/ui/` |
| http-клиент, офлайн-очередь | `shared/api/` |
| утилита без бизнес-смысла | `shared/lib/` |
| правило карточек, Лейтнер, статистика без React | `packages/core`, не сюда |

## Антипаттерны

1. Мелкие фичи. Фича на кнопку размывает границы, объедини с соседями.
2. Импорт из `app`. Там самый часто меняющийся код, зависимость на него ломает фичи.
3. Импорт внутренностей чужой фичи мимо `index.ts`.
4. Бизнес-правила в компонентах. Чистая логика без React уходит в `packages/core`.
